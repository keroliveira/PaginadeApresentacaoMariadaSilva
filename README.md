# Pagina de Apresentação Maria da Silva
Essa página web, estilo portfólio, foi desenvolvido durante os dois últimos módulos dos cursos da formação "A partir do zero: HTML e CSS para projetos Web" da Alura. A ideia foi construir uma página para a profissional fictícia Maria da Silva, especialista em Front-end, visando sua apresentação bem como das suas principais redes sociais/contatos.
